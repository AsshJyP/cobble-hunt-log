# Cobble Hunt Log

Mod **solo de cliente** para Minecraft **1.21.1 (Fabric)** con **Cobblemon 1.7.x**.

- Graba en archivos de texto tus combates contra Pokémon salvajes especiales: shiny, legendarios, míticos y ultraentes (o todos, si lo eliges).
- Contador opcional de caza de shiny con HUD: encuentros por especie, tiempo y probabilidad acumulada.
- Menú de opciones con la tecla **H** o desde Mod Menu.

Solo usa la información de tus propios combates, la misma que ves en pantalla. No escanea el mundo ni avisa de spawns.

- Requiere: Fabric Loader ≥ 0.16.0, Fabric API y Cobblemon ≥ 1.7.0. Recomendado: Mod Menu.
- Licencia: MIT. Pokémon es una marca de Nintendo/Game Freak/The Pokémon Company.

## Compilar
```
.\gradlew build
```
El `.jar` queda en `build/libs/`.
